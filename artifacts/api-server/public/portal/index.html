How to Install

Works with any website — WordPress, Wix, Squarespace, Webflow, or hand-coded HTML.

1
Copy the embed code above by clicking Copy.
2
Open your website editor and find the </body> closing tag (usually in a footer or theme settings area).
3
Paste the code just before the </body> closing tag and save/publish.
4
Visit your website — a chat bubble will appear in the bottom-right corner. Click it to open the widget.
