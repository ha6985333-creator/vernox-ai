You are building the core lead tracking system for Vernox AI. Right now, when customers 
book through the AI chatbot, there's no way to see those leads or track them. This breaks 
trust and prevents you from proving ROI.

CURRENT STATE:
- Backend: Node.js/Express
- Database: PostgreSQL via Supabase
- AI chatbot: Already captures customer info and creates Google Calendar events
- Frontend: React tenant portal with Reservations tab (currently empty)

THE PROBLEM:
When a lead books through the AI:
1. The appointment goes to Google Calendar (good)
2. But there's NO record in your database of that lead
3. Business owner can't see who inquired
4. No lead history, no data, no trust

YOUR TASK:
Build a complete leads management system where:
1. Every chatbot conversation creates a lead record
2. Business owner sees all leads in the dashboard
3. Can see conversation history, customer details, booking status
4. Can filter and sort leads

IMPLEMENTATION REQUIREMENTS:

### STEP 1: Create Leads Database Schema

```sql
-- Main leads table
CREATE TABLE leads (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  business_id UUID NOT NULL REFERENCES businesses(id) ON DELETE CASCADE,
  location_id UUID REFERENCES locations(id), -- If multi-location support
  
  -- Customer info captured from chat
  customer_name VARCHAR(255),
  customer_email VARCHAR(255),
  customer_phone VARCHAR(20),
  customer_notes TEXT, -- Any special requests from the chat
  
  -- Lead status
  status VARCHAR(50) DEFAULT 'new', -- 'new', 'contacted', 'booked', 'no_show', 'converted', 'lost'
  quality_score INTEGER DEFAULT 50, -- 1-100 rating (50 = neutral)
  
  -- Booking info
  requested_service VARCHAR(255), -- What they asked for
  preferred_datetime TIMESTAMP, -- What time they wanted
  booked_datetime TIMESTAMP, -- When they actually booked
  calendar_event_id VARCHAR(255), -- Link to Google Calendar event
  is_booked BOOLEAN DEFAULT false,
  
  -- Tracking
  conversation_id VARCHAR(255), -- Link to chat history
  conversation_transcript TEXT, -- Full chat log
  source VARCHAR(50) DEFAULT 'chat', -- 'chat', 'phone', 'manual'
  
  -- Timestamps
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  contacted_at TIMESTAMP, -- When business owner first contacted them
  
  -- Soft delete
  deleted_at TIMESTAMP
);

-- Lead activity history (for tracking changes)
CREATE TABLE lead_activities (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  lead_id UUID NOT NULL REFERENCES leads(id) ON DELETE CASCADE,
  business_id UUID NOT NULL REFERENCES businesses(id),
  activity_type VARCHAR(100), -- 'status_changed', 'contacted', 'email_sent', 'note_added'
  description TEXT,
  created_by VARCHAR(255), -- admin email or 'system'
  created_at TIMESTAMP DEFAULT NOW()
);

-- Lead notes (admin can add private notes)
CREATE TABLE lead_notes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  lead_id UUID NOT NULL REFERENCES leads(id) ON DELETE CASCADE,
  business_id UUID NOT NULL REFERENCES businesses(id),
  note_text TEXT,
  created_by VARCHAR(255),
  created_at TIMESTAMP DEFAULT NOW()
);
```

### STEP 2: Update AI Chatbot to Create Lead Records

When the AI completes a conversation and books an appointment, it should:
1. Save the lead to the leads table
2. Store the conversation transcript
3. Link to the Google Calendar event
4. Set initial status to 'booked' if appointment confirmed

Update your booking endpoint:

```javascript
// backend/routes/bookings.js

app.post('/api/bookings/create', async (req, res) => {
  const { 
    businessId, 
    customerName, 
    customerEmail, 
    customerPhone,
    requestedService,
    bookedDateTime,
    conversationTranscript,
    conversationId
  } = req.body;
  
  try {
    // 1. Create Google Calendar event (existing code)
    const calendarEvent = await calendar.events.insert({
      calendarId: business.google_calendar_id,
      requestBody: {
        summary: `${customerName} - ${requestedService}`,
        start: { dateTime: bookedDateTime },
        end: { dateTime: addMinutes(bookedDateTime, business.booking_duration_minutes) },
        description: `Lead ID: ${leadId}\nPhone: ${customerPhone}`
      }
    });
    
    // 2. Create lead record in database (NEW)
    const leadId = await db.query(
      `INSERT INTO leads (
        business_id, customer_name, customer_email, customer_phone,
        requested_service, booked_datetime, calendar_event_id,
        conversation_transcript, conversation_id, is_booked, status
      ) VALUES ($1, $2, $3, $4, $5, $6, $7, $8, $9, true, 'booked')
      RETURNING id`,
      [
        businessId,
        customerName,
        customerEmail,
        customerPhone,
        requestedService,
        bookedDateTime,
        calendarEvent.id,
        conversationTranscript,
        conversationId
      ]
    );
    
    // 3. Log the activity
    await db.query(
      'INSERT INTO lead_activities (lead_id, business_id, activity_type, description) VALUES ($1, $2, $3, $4)',
      [leadId[0].id, businessId, 'booked', `Booking created via AI chatbot`]
    );
    
    res.json({ success: true, leadId: leadId[0].id });
  } catch (error) {
    console.error('Booking error:', error);
    res.status(500).json({ error: 'Failed to create booking' });
  }
});
```

### STEP 3: Create Leads API Endpoints

Build these endpoints for the frontend:

```javascript
// backend/routes/leads.js

// GET all leads for a business
app.get('/api/leads', authenticateUser, async (req, res) => {
  const { businessId } = req.query;
  const { status, sortBy, limit = 50, offset = 0 } = req.query;
  
  let query = 'SELECT * FROM leads WHERE business_id = $1 AND deleted_at IS NULL';
  let params = [businessId];
  
  // Filter by status if provided
  if (status && status !== 'all') {
    query += ` AND status = $${params.length + 1}`;
    params.push(status);
  }
  
  // Sort options
  const sortOptions = {
    newest: 'ORDER BY created_at DESC',
    oldest: 'ORDER BY created_at ASC',
    booked: 'ORDER BY booked_datetime DESC',
    quality: 'ORDER BY quality_score DESC'
  };
  
  query += ` ${sortOptions[sortBy] || sortOptions.newest}`;
  query += ` LIMIT $${params.length + 1} OFFSET $${params.length + 2}`;
  params.push(limit, offset);
  
  const leads = await db.query(query, params);
  
  // Count total for pagination
  const countQuery = 'SELECT COUNT(*) as count FROM leads WHERE business_id = $1 AND deleted_at IS NULL';
  let countParams = [businessId];
  if (status && status !== 'all') {
    countQuery += ` AND status = $2`;
    countParams.push(status);
  }
  const countResult = await db.query(countQuery, countParams);
  
  res.json({
    leads: leads.rows,
    total: countResult.rows[0].count,
    limit,
    offset
  });
});

// GET single lead with full conversation
app.get('/api/leads/:leadId', authenticateUser, async (req, res) => {
  const { leadId } = req.params;
  
  const lead = await db.query(
    'SELECT * FROM leads WHERE id = $1',
    [leadId]
  );
  
  const activities = await db.query(
    'SELECT * FROM lead_activities WHERE lead_id = $1 ORDER BY created_at DESC',
    [leadId]
  );
  
  const notes = await db.query(
    'SELECT * FROM lead_notes WHERE lead_id = $1 ORDER BY created_at DESC',
    [leadId]
  );
  
  res.json({
    lead: lead.rows[0],
    activities: activities.rows,
    notes: notes.rows
  });
});

// UPDATE lead status
app.put('/api/leads/:leadId/status', authenticateUser, async (req, res) => {
  const { leadId } = req.params;
  const { status } = req.body;
  
  const validStatuses = ['new', 'contacted', 'booked', 'no_show', 'converted', 'lost'];
  if (!validStatuses.includes(status)) {
    return res.status(400).json({ error: 'Invalid status' });
  }
  
  await db.query(
    'UPDATE leads SET status = $1, updated_at = NOW() WHERE id = $2',
    [status, leadId]
  );
  
  // Log the activity
  await db.query(
    'INSERT INTO lead_activities (lead_id, business_id, activity_type, description) VALUES ($1, $2, $3, $4)',
    [leadId, req.body.businessId, 'status_changed', `Status changed to ${status}`]
  );
  
  res.json({ success: true });
});

// UPDATE lead quality score
app.put('/api/leads/:leadId/score', authenticateUser, async (req, res) => {
  const { leadId } = req.params;
  const { score } = req.body;
  
  if (score < 1 || score > 100) {
    return res.status(400).json({ error: 'Score must be 1-100' });
  }
  
  await db.query(
    'UPDATE leads SET quality_score = $1, updated_at = NOW() WHERE id = $2',
    [score, leadId]
  );
  
  res.json({ success: true });
});

// ADD note to lead
app.post('/api/leads/:leadId/notes', authenticateUser, async (req, res) => {
  const { leadId } = req.params;
  const { note } = req.body;
  
  await db.query(
    'INSERT INTO lead_notes (lead_id, business_id, note_text, created_by) VALUES ($1, $2, $3, $4)',
    [leadId, req.body.businessId, note, req.user.email]
  );
  
  res.json({ success: true });
});

// GET lead statistics for dashboard
app.get('/api/leads/stats/:businessId', authenticateUser, async (req, res) => {
  const { businessId } = req.params;
  
  const stats = await db.query(`
    SELECT
      COUNT(*) as total_leads,
      SUM(CASE WHEN is_booked = true THEN 1 ELSE 0 END) as total_booked,
      SUM(CASE WHEN is_booked = true THEN 1 ELSE 0 END)::float / 
        NULLIF(COUNT(*), 0) * 100 as conversion_rate,
      SUM(CASE WHEN status = 'no_show' THEN 1 ELSE 0 END) as no_shows,
      AVG(quality_score) as avg_quality_score
    FROM leads
    WHERE business_id = $1 AND deleted_at IS NULL
  `, [businessId]);
  
  res.json(stats.rows[0]);
});
```

### STEP 4: Update React Dashboard to Display Leads

Update the Reservations tab in your tenant portal:

```jsx
// frontend/pages/Leads.jsx

import React, { useEffect, useState } from 'react';

export default function LeadsPage() {
  const [leads, setLeads] = useState([]);
  const [stats, setStats] = useState(null);
  const [filter, setFilter] = useState('all');
  const [selectedLead, setSelectedLead] = useState(null);
  
  useEffect(() => {
    fetchLeads();
    fetchStats();
  }, [filter]);
  
  const fetchLeads = async () => {
    const res = await fetch(`/api/leads?businessId=${businessId}&status=${filter}`);
    const data = await res.json();
    setLeads(data.leads);
  };
  
  const fetchStats = async () => {
    const res = await fetch(`/api/leads/stats/${businessId}`);
    const data = await res.json();
    setStats(data);
  };
  
  const handleStatusChange = async (leadId, newStatus) => {
    await fetch(`/api/leads/${leadId}/status`, {
      method: 'PUT',
      body: JSON.stringify({ status: newStatus, businessId })
    });
    fetchLeads();
  };
  
  if (!stats) return <div>Loading...</div>;
  
  return (
    <div className="leads-container">
      {/* Summary Stats */}
      <div className="stats-grid">
        <div className="stat-card">
          <div className="stat-number">{stats.total_leads}</div>
          <div className="stat-label">Total Leads</div>
        </div>
        <div className="stat-card">
          <div className="stat-number">{stats.total_booked}</div>
          <div className="stat-label">Booked</div>
        </div>
        <div className="stat-card">
          <div className="stat-number">{Math.round(stats.conversion_rate)}%</div>
          <div className="stat-label">Conversion Rate</div>
        </div>
        <div className="stat-card">
          <div className="stat-number">{stats.no_shows}</div>
          <div className="stat-label">No Shows</div>
        </div>
      </div>
      
      {/* Filter Tabs */}
      <div className="filter-tabs">
        {['all', 'new', 'contacted', 'booked', 'converted', 'lost'].map(status => (
          <button
            key={status}
            className={`tab ${filter === status ? 'active' : ''}`}
            onClick={() => setFilter(status)}
          >
            {status.charAt(0).toUpperCase() + status.slice(1)}
          </button>
        ))}
      </div>
      
      {/* Leads List */}
      <div className="leads-list">
        {leads.length === 0 ? (
          <div className="empty-state">
            <p>No leads yet. They'll appear here once customers start booking.</p>
          </div>
        ) : (
          leads.map(lead => (
            <div key={lead.id} className="lead-card">
              <div className="lead-header">
                <div className="lead-name">{lead.customer_name}</div>
                <div className={`lead-status ${lead.status}`}>{lead.status}</div>
              </div>
              <div className="lead-details">
                <p><strong>Email:</strong> {lead.customer_email}</p>
                <p><strong>Phone:</strong> {lead.customer_phone}</p>
                <p><strong>Service:</strong> {lead.requested_service}</p>
                <p><strong>Booked:</strong> {new Date(lead.booked_datetime).toLocaleString()}</p>
              </div>
              <div className="lead-actions">
                <select 
                  value={lead.status}
                  onChange={(e) => handleStatusChange(lead.id, e.target.value)}
                >
                  <option value="new">New</option>
                  <option value="contacted">Contacted</option>
                  <option value="booked">Booked</option>
                  <option value="converted">Converted</option>
                  <option value="lost">Lost</option>
                  <option value="no_show">No Show</option>
                </select>
                <button onClick={() => setSelectedLead(lead.id)}>
                  View Conversation
                </button>
              </div>
            </div>
          ))
        )}
      </div>
      
      {/* Lead Detail Modal */}
      {selectedLead && (
        <div className="modal">
          <div className="modal-content">
            <h2>Conversation History</h2>
            <div className="conversation">
              {leads.find(l => l.id === selectedLead)?.conversation_transcript}
            </div>
            <button onClick={() => setSelectedLead(null)}>Close</button>
          </div>
        </div>
      )}
    </div>
  );
}
```
