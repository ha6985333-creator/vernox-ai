TASK 2: BACKEND — BETTER ERROR HANDLING
In artifacts/api-server/src/routes/reviews.ts:

When calling analyzeReview(review):
- Wrap in try-catch
- On Groq success:
  - Set groq_call_status = 'success'
  - Clear groq_error_message
  - Update last_groq_attempt_at = now
  - Reset groq_retry_count = 0
- On Groq failure (timeout, rate limit, API error):
  - Set groq_call_status = 'failed'
  - Log full error: logger.error({ error, reviewId, tenantId })
  - Set groq_error_message = error.message (first 500 chars)
  - Increment groq_retry_count
  - Return 502 with user-friendly message: "Analysis failed. We'll retry in 1 hour."
  - Do NOT silently swallow errors with .catch(() => {})

POST /api/reviews/:id/regenerate
- Check if groq_retry_count >= 3 and last_groq_attempt_at < 1 hour ago
- If so, return 429: "Too many retries. Please try again in 1 hour."
- Otherwise, proceed with analysis

TASK 5: FRONTEND JAVASCRIPT
In portal/index.html app.js:

const loadReviewAnalytics = async () => {
  const response = await fetch("/api/reviews/analytics", { credentials: "include" });
  if (!response.ok) return; // silent fail, show cached data
  const analytics = await response.json();
  
  document.getElementById("totalReviewsCount").textContent = analytics.totalReviews;
  document.getElementById("averageRatingValue").textContent = analytics.averageRating.toFixed(1) + "★";
  document.getElementById("pendingAnalysisCount").textContent = analytics.analysisStatus.failed;
  document.getElementById("pendingApprovalCount").textContent = analytics.pendingApproval;
  
  // Sources breakdown
  const sourcesList = Object.entries(analytics.reviewsBySource)
    .map(([source, count]) => `<div>${source}: ${count}</div>`)
    .join("");
  document.getElementById("reviewSourcesBreakdown").innerHTML = sourcesList;
  
  // Sentiment breakdown
  const sentimentList = Object.entries(analytics.reviewsBySentiment)
    .map(([sentiment, count]) => `<div>${sentiment}: ${count}</div>`)
    .join("");
  document.getElementById("sentimentBreakdown").innerHTML = sentimentList;
  
  // Show failed analyses warning if any
  if (analytics.recentFailures.length > 0) {
    const warning = `<div class="warning">⚠️ ${analytics.recentFailures.length} review(s) failed analysis. Check back soon — we'll retry automatically.</div>`;
    document.getElementById("review-analytics").insertAdjacentHTML("beforeend", warning);
  }
};

// Call on tab load
window.addEventListener("hashchange", () => {
  if (location.hash === "#reviews") { loadReviewAnalytics(); loadReviews(); }
});
