You are enhancing Vernox AI to make the AI chatbot industry-specific. Currently, the AI 
is generic and asks generic questions. After this update, it will know what business it's 
serving and ask targeted questions.

CURRENT STATE:
- Backend: Node.js/Express
- Database: PostgreSQL via Supabase

- AI: Groq API with generic system prompt

THE PROBLEM:
A restaurant's AI asks the same questions as a dentist's AI. This is weak. The AI should:
- Ask restaurant-specific questions: "How many guests? Dietary restrictions?"
- Ask dentist-specific questions: "What service? Emergency or routine?"
- Personalize responses with business name
- Only offer services that business actually provides

YOUR TASK:
Build a system where the AI knows its business context and adjusts behavior accordingly.

### STEP 4: Create Business-Specific AI Prompts

Build a prompt factory that generates industry-specific prompts:

```javascript
// backend/prompts/industryPrompts.js

const industryPrompts = {
  restaurant: {
    systemPrompt: `You are the AI assistant for {businessName}, a restaurant.
    
Your job: Capture reservations and qualify dining inquiries.

Available services: {services}

When a customer contacts you:
1. Ask: "How many guests are you booking for?"
2. Ask: "What date and time would work best?"
3. Ask: "Do you have any dietary restrictions we should know about?"
4. Capture their name and phone number

If they mention a service not offered, say: "We don't offer that, but we specialize in {services}. 
Would a {service} work instead?"

Be warm, friendly, and like you work at an actual restaurant.`,
    
    variables: ['businessName', 'services']
  },

  dentist: {

Your job: Schedule appointments and qualify dental inquiries.

Available services: {services}

When a customer contacts you:

2. Ask: "Are you an existing patient or new?"

5. Confirm the appointment

Be professional, reassuring, and answer basic dental questions if asked.`,
    
    variables: ['businessName', 'services']
  },

  plumber: {

Your job: Capture service requests and schedule appointments.

Available services: {services}

When a customer contacts you:

Be practical, reassuring about emergency services, and knowledgeable about plumbing.`,

Available services: {services}

When a customer contacts you:
1. Ask: "What service are you interested in? ({services})"
2. Ask: "Do you have a preferred stylist?"
3. Ask: "When would you like to come in?"
4. Capture their name and phone number
5. Confirm the appointment

Be friendly, fashion-forward, and enthusiastic about services.`,
    
    variables: ['businessName', 'services']
  },

  // Add more industries as needed
  default: {
    systemPrompt: `You are an AI assistant for {businessName}.

Your job: Help customers book appointments and answer questions.

Available services: {services}

When a customer contacts you:
1. Ask what they need
2. Confirm the best time
3. Capture their contact information
4. Confirm the booking

Be helpful, professional, and friendly.`,
    
    variables: ['businessName', 'services']

// Function to generate the actual prompt
function generateSystemPrompt(businessType, businessName, services) {
  const template = industryPrompts[businessType?.toLowerCase()] || industryPrompts.default;
  
  let prompt = template.systemPrompt;
  prompt = prompt.replace('{businessName}', businessName);
  prompt = prompt.replace(/{services}/g, services.join(', '));
  
  return prompt;
}

module.exports = { generateSystemPrompt };
```

### STEP 5: Update Groq API Call to Use Business Context

When calling Groq AI, use the business-specific prompt:

```javascript
// backend/routes/chat.js

const { generateSystemPrompt } = require('../prompts/industryPrompts');

app.post('/api/chat', async (req, res) => {
  const { businessId, userMessage } = req.body;
  
  // Get business details
  const business = await db.query(
    'SELECT business_name, business_type, services FROM businesses WHERE id = $1',
    [businessId]
  );
  
  // Generate business-specific system prompt
  const systemPrompt = generateSystemPrompt(
    business.business_type,
    business.business_name,
    business.services || []
  );
  
  // Call Groq with the business-specific prompt
  const response = await groq.chat.completions.create({
    model: "mixtral-8x7b-32768", // or your preferred model
    messages: [
      {
        role: "system",
        content: systemPrompt  // <-- NOW BUSINESS-SPECIFIC
      },
      {
        role: "user",
        content: userMessage
      }
    ],
    max_tokens: 500,
    temperature: 0.7
  });
  
  res.json({ reply: response.choices[0].message.content });
});
```
